## Mục tiêu
Cài hook log AI của BTC và bộ luật / skill của đội trên máy mình; kiểm log thật sự được ghi.

Log AI là phần "AI Usage" trong rubric BTC — mất log ngày đầu thì không lấy lại được. Luật + skill giúp AI agent của mình làm đúng kiến trúc chung.

2. `cp .env.example .env`, điền `AI_LOG_API_KEY` (dashboard Phoenix) và `OPENAI_API_KEY`
3. `pip install -r requirements.txt pre-commit` trong venv Python 3.11
4. `bash ../team-ai-kit/install.sh` (Windows Git Bash: thêm `--copy`)
5. Mở Claude Code / Cursor, gõ 1 prompt bất kỳ
