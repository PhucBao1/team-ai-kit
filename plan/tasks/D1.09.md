## Các bước
1. HMAC-SHA256 với `CONFIRM_TOKEN_SECRET`
2. Hết hạn theo đồng hồ giả lập
3. Audit mỗi lần ghi
4. So chữ ký bằng `hmac.compare_digest`; token dùng 1 lần; không đưa token vào URL / log
5. HMAC phủ action + hash params + customer_id (lấy từ PHIÊN, không từ LLM) + hạn + nonce
6. Production thiếu `CONFIRM_TOKEN_SECRET` → app không khởi động (đã có trong config)
