# 21 · Frontend engineering — Ba màn hình realtime, người lớn tuổi dùng được, mạng yếu không vỡ

> Trích từ Technical spec & kế hoạch build. Nguồn gốc: file HTML cùng tên. Sửa nội dung ở file HTML rồi chạy lại script chuyển đổi, hoặc sửa file .md này và ghi chú trong PR.

| Chủ đề | Thiết kế |
| --- | --- |
| Kiến trúc | React + TypeScript; **TanStack Query** cho dữ liệu server (jobs, handoffs); store nhỏ (Zustand) cho trạng thái giao diện; kiểu dữ liệu sinh từ OpenAPI của FastAPI để FE–BE không lệch |
| Realtime | Hook SSE tự nối lại có backoff, gửi Last-Event-ID để không mất tin; bỏ trùng theo message id; hiển thị trạng thái kết nối |
| Xác nhận | Cập nhật lạc quan khi khách bấm Xác nhận (nút khoá, hiện "đang đặt"), hoàn tác nếu server từ chối; **không bao giờ** hiện "đã đặt" trước khi server xác nhận |
| Mạng yếu | Hàng đợi tin gửi khi mất mạng; thông báo rõ; không gửi lặp (idempotency key từ client) |
| Accessibility | WCAG 2.2 AA: tương phản, cỡ chữ phóng to không vỡ bố cục (khách lớn tuổi), điều hướng bàn phím, nhãn cho trình đọc màn hình, không chỉ dùng màu để báo trạng thái |
| Design system | Token màu / chữ / khoảng cách dùng chung; component chung cho 3 màn hình (thẻ việc, thanh tiến độ, card handoff, bong bóng chat) |
| Hiệu năng | Tách code theo màn hình; danh sách ảo hoá cho console nhiều handoff; ngân sách: tải trang đầu < 2 giây trên 4G |
| Đo trải nghiệm | Sự kiện UX: thời gian đến lúc xác nhận, tỷ lệ bỏ giữa chừng, số lần bấm "Gặp nhân viên" → đưa vào dashboard (§22 tầng 5) |
| Bảo mật | Không lưu token dài hạn ở localStorage; CSP; confirmation token chỉ tồn tại trong phiên |
| Kiểm thử | Vitest cho component; Playwright e2e cho luồng demo; so ảnh (visual regression) cho 3 màn hình |
